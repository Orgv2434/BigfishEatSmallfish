# tripo_fish ai绘画-建模使用说明

## API设置

1. Hierarchy-> Tripo_Manager -> TripoController：输入Tripo3D APIkey (tsk_ ...)
2. Hierarchy-> Tripo_Manager -> SketchDemo：输入“触站ai” APIkey (tcli_ ...)

触站ai：[API开放平台](https://open.czhanai.com/platform)

tripo3d：[Tripo API | Integrate, Automate, and Scale with AI 3D Modeling](https://www.tripo3d.ai/api)
